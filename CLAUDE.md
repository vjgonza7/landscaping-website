Build a premium cinematic landscaping and irrigation website for VIRENZA.

The site must feel:
- luxury
- modern
- cinematic
- high-end Arizona landscaping
- Apple/Tesla/Awwwards quality
- emotionally focused on transformation

Turn visitors into quote requests.

## Critical Hero Requirement

The hero must show a transformation:

Start:
- dead/dry Arizona yard
- cracked dirt
- broken sprinkler
- leaking irrigation
- dead grass
- messy neglected yard

Then:
- mower worker enters
- mower worker passes through the yard
- leaks get fixed
- grass becomes vibrant green
- luxury landscaping appears
- warm lighting appears

End:
- beautiful luxury green yard
- no leaks
- clean irrigation
- premium landscaping

## Mower Worker Requirement

The mower worker is critical.

The client wants the mower worker from the reference image.

Do NOT use:
- blocky mower
- cube mower
- placeholder geometry
- cartoon mower
- generic 3D object
- low-quality SVG placeholder

Use either:
1. the actual mower/worker visually extracted or cropped from the reference image, OR
2. a high-quality detailed 2.5D illustrated version that closely matches it.

The mower must have:
- green mower body
- black wheels
- visible seat
- mower deck
- handles
- worker in green/black uniform
- cap
- VIRENZA branding feel

## Animation Rules

Preferred animation:
- stable 2.5D layered reveal
- scroll-driven
- clip-path / mask reveal
- Framer Motion or CSS transforms
- no runtime crashes

The mower is the reveal driver.

Behavior:
- bad yard is visible first
- mower moves through the yard
- green luxury yard is revealed behind mower
- broken sprinkler/leaks fade away behind mower
- glowing divider follows mower
- transformation feels smooth and cinematic

Avoid:
- unstable React Three Fiber terrain
- procedural grass fields
- particle systems that crash
- overcomplicated 3D
- choppy animations

## Development Rules

Before making changes:
- inspect existing files
- understand current structure
- preserve working pieces

When fixing:
- make the smallest effective change
- do not restart from scratch
- do not rewrite the whole site
- do not delete working backend code

After changes:
- run the site locally
- check for runtime errors
- explain what files changed
- explain how to test it
